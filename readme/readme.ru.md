# FluxDrop (Русский)

Быстрая передача файлов, фото, папок и текста между устройствами напрямую: без интернета, без облака, без аккаунтов и без регистрации. Устройства находят друг друга в локальной Wi-Fi сети или соединяются напрямую через Google Nearby / Wi-Fi Direct, если роутера рядом нет.

**Текущая версия: 0.5.0** · Android 8.0+ (minSdk 26) · Kotlin + Jetpack Compose (Material 3)

## Возможности

- **Пакет отправки:** Собирайте файлы, фото, папки или текст, затем выбирайте получателя.
- **Кнопка «Фото»:** Быстрый выбор изображений отдельной кнопкой рядом с файлами и папками.
- **Передача по NFC в одно касание:** Свайп вниз на главном экране открывает панель «Приложите телефон». Касание телефонами передаёт пакет: метка несёт имя и id отправителя, FluxDrop на втором телефоне сам находит это устройство по Nearby, подключается и забирает пакет — локальный сайт не открывается. Если приложения нет, метка ведёт на страницу скачивания.
- **Чёрная тема по умолчанию:** Настоящий чёрный Material 3, светлая тема — в настройках «Оформление». Без динамического цвета.
- **Кнопка QR-кода на главном экране:** Быстрый показ QR-кода веб-портала прямо со статусной карточки главного экрана для передачи на ПК или iPhone без установки приложения.
- **Два канала передачи:**
  - **LAN:** Активный UDP-broadcast каждые 2 секунды с `MulticastLock`; работает в локальной сети и точке доступа (хотспоте).
  - **Nearby:** Google Nearby Connections (BLE + Wi-Fi Direct) для связи напрямую без роутера.
- **Безопасность Nearby:**
  - Для недоверенных устройств сессия сбрасывается после отправки, поэтому запрос на приём появляется при каждой новой передаче.
  - В шторку добавлена кнопка «Всегда принимать (Доверенное)» для быстрого добавления в доверенные.
- **Входящая шторка:** Показывается поверх любых приложений, даже когда FluxDrop свёрнут.
- **Высокая скорость и докачка:** Чанки по 16 МБ с SHA-256; передача продолжается с места обрыва.
- **Мультиязычность:** Полная поддержка английского и русского языков с автоматическим выбором языка системы или ручным переключением в настройках.
- **Плитка в шторке Android:** Отправка буфера обмена в один тап.

## Установка

1. Откройте [Releases](../../releases) и скачайте свежий `FluxDrop-*.apk`.
2. Откройте файл на телефоне и подтвердите установку.
3. Выдайте разрешения (Уведомления, Устройства рядом, Память).
